운영 소개 · 계산 기준

도토리 계산기는 직장인과 자취생이 매달 반복해서 확인하는 생활비·세금 숫자를, 공식 요율 그대로 빠르게 계산하기 위해 만든 무료 도구 모음입니다.

왜 만들었나

연말정산 시즌이 되면 같은 계산을 여러 번 합니다. 중소기업 감면을 받을 수 있는지, 월세 세액공제와 현금영수증 중 무엇이 유리한지, 여름에 에어컨을 켜면 전기요금이 얼마나 오르는지. 대부분은 공식 요율과 내 숫자 몇 개만 있으면 답이 나오는데, 계산기마다 기준 연도가 다르고 광고가 먼저 보입니다.

그래서 숫자를 한눈에 크게 보여주고, 어떤 근거로 그 숫자가 나왔는지를 같은 페이지에 남기는 방식으로 다섯 개를 만들었습니다. 로그인도, 앱 설치도, 개인정보 입력도 필요 없습니다.

계산 기준과 출처

  • 중소기업 취업자 소득세 감면 — 조세특례제한법 제30조, 소득세법 제55조(기본세율), 국세기본법 제45조의2(경정청구 5년). 감면율 청년 90%·그 외 70%, 연 200만원 한도, 지방소득세 10% 포함.
  • 전기요금 누진제 — 한국전력공사 주택용 요금표. 2026년 11월 기준 저압 전력량요금 120.0 / 214.6 / 307.3원·기본요금 910 / 1,600 / 7,300원, 고압 105.0 / 174.0 / 242.3원·730 / 1,260 / 6,060원. 누진 경계는 일반 계절 200 / 400kWh, 하계 300 / 450kWh이며 1,000kWh 초과분은 슈퍼유저 요금(저압 736.2원·고압 593.3원)이 적용됩니다. 기후환경요금 9원, 연료비조정요금 5원, 부가세 10%, 전력산업기반기금 2.7%(2025.7.1 인하), 10원 미만 절사.
  • K-패스·기후동행카드 — 국토교통부 K-패스 환급률(일반 20%·청년 30%·다자녀 2자녀 30%·3자녀 50%·저소득 53%, 월 15회 이상·60회 한도), 서울시 기후동행카드 요금(62,000·65,000원, 청년 55,000·58,000원).
  • 월세 세액공제 — 조세특례제한법 제95조의2. 총급여 5,500만원 이하 17%, 5,500만~8,000만원 15%, 연 1,000만원 한도. 현금영수증 소득공제는 월세액 30%, 한도 300만·250만원.
  • AI 구독 요금 — 각 서비스 공식 요금 페이지. ChatGPT 13,000·29,000원, Google AI Plus 7,500원, Claude Pro $22, Perplexity Pro $20.

정확성의 한계

세금 계산은 부양가족 수, 4대보험료, 연금계좌·보험료 공제, 다른 감면을 반영하지 않은 간이 추정입니다. 실제 결정세액은 사람마다 다르므로, 원천징수영수증의 결정세액을 직접 입력하는 방식을 함께 제공합니다. 전기요금은 계약 종별(저압·고압)과 계절 구간을 선택해 반영하지만, 복지할인·TV수신료·연체료·공용 전기료는 포함하지 않습니다.

법령과 요금은 바뀝니다. 계산 결과는 의사결정을 돕는 참고값이고, 신고·환급·계약의 최종 판단은 국세청 홈택스, 한국전력, 지방자치단체 등 원문을 확인한 뒤 내려 주세요. 오류를 발견하면 문의로 알려주시면 확인 후 고치겠습니다.

운영 방식

이 사이트는 GitHub Pages로 호스팅되는 정적 웹사이트입니다. 서버·데이터베이스가 없고, 모든 계산은 방문자의 브라우저에서 JavaScript로만 실행됩니다. 운영 비용은 광고 수익으로 충당하며, 광고가 계산 결과를 가리지 않도록 본문 아래에만 배치합니다.

업데이트는 요율이 바뀌거나 오류가 확인될 때 반영하고, 각 페이지 상단의 기준일로 시점을 표시합니다.
